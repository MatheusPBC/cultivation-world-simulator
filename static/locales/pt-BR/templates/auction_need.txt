Você decide, para um único cultivador, o quanto ele precisa de cada lote ofertado em um leilão.

O cultivador para quem você decide:
avatar_id: {avatar_id}
{avatar_info}

Saldo atual deste cultivador: {current_balance} pedras espirituais.

Os lotes ofertados são estes, cada um com o máximo que este cultivador
realmente comprometeria em cada nível:
{lots}

O que cada nível compromete materialmente:
- 1: nenhum lance.
- 2: até 0,8x o preço base.
- 3: até 1,5x o preço base.
- 4: até 3x o preço base.
- 5: todo o saldo atual.
Todos os níveis são limitados pelo saldo mostrado, e compras anteriores no
mesmo leilão reduzem o que resta. Você escolhe um nível, nunca um preço.

Atenção: retorne o resultado apenas em formato JSON.
O formato é um mapeamento plano de lot_key para nível de necessidade:
{{
    "{{lot_key_1}}": int,
    "{{lot_key_2}}": int,
    ...
}}

Requisitos:
1. Decida apenas para este único cultivador. Não mencione nem decida por mais ninguém.
2. Refira-se a cada lote pela string exata de lot_key. Dois lotes podem compartilhar o mesmo item_id; ainda assim são lotes diferentes e são avaliados separadamente.
3. O nível de necessidade deve ser um dos inteiros 1, 2, 3, 4, 5 — nada além disso. 1 significa totalmente desnecessário, 5 significa absolutamente necessário.
4. Retorne um inteiro puro, nunca um decimal, nunca uma string entre aspas, e nunca um valor fora de 1-5. Qualquer outro valor é rejeitado e conta como nenhum lance.
5. Você pode omitir um lote; um lote omitido simplesmente conta como nenhum lance.
6. Julgue pelas circunstâncias do próprio cultivador. Por exemplo, quem está perto do fim da longevidade precisa mais de um elixir de longevidade.
